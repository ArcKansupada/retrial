Step one — a decorator, not an export format

your agent loop
@record(session_name="booking-agent") def run_agent(messages, tools=TOOLS, call_model=call_model, execute_tools=execute_tools): while True: r = call_model(messages, tools) messages.append(assistant(r)) if r.stop_reason != "tool_use": return r messages.append(execute_tools(r))

One rule: messages is a parameter. That is what lets a fork seed your loop with edited history and get genuine re-execution.

Same machinery, pointed at a failure

A run failed five steps ago. Which step doomed it?

$ retrial bisect s_0abbad608c --check "output contains 'Confirmed'"
probe step 2 d157261  recovered  → 'Confirmed: AUS-SFO booked for $450…'
probe step 3 3883e2a  still broken  → "I couldn't reach the airline to book that."

First step that could not recover: 3883e2a — ran book_flight

2 re-executions over 5 candidate steps. Binary search over resume points, each probe a real run of your agent, each one recorded as its own session you can open.

Fork plus a check, aimed at four more questions

ablateWhich recorded facts did a good run actually need? Perturb each, watch the outcome flip.
sweepFork one step across many values to find the real threshold in the model's behavior.
rerunRe-execute every recorded run against today's code. Your traces are the regression suite.
costTokens and dollars per step. An unknown model prices as unpriced, never as a guess.
